AA. How Does This System Work?From age-filtered records to a model result
01

Build the cohort

The provided diabetes dataset is filtered to adults aged 20 to 60 inclusive. The saved evaluation records 741 rows in this cohort.

02

Prepare five features

The pipeline uses Glucose, BMI, BloodPressure, Insulin, and Age. Recorded zero values for clinical measures are treated as missing and imputed within the fitted pipeline.

03

Evaluate and select

Logistic Regression, Support Vector Machine, and Random Forest were compared using five-fold stratified cross-validation. The selected model is shown in the project metrics.

04

Return a pattern

The saved model evaluates the five submitted values and returns a lower or higher predicted risk pattern. This output is educational and not diagnostic.

BB. What Do These Five Parameters Mean?Input definitions and units
  • Glucose mg/dL

    Blood glucose concentration as recorded for the reading.

  • BMI kg/m²

    Body mass index, a ratio based on weight and height.

  • Blood Pressure mmHg

    Blood pressure value recorded in the source dataset.

  • Insulin µU/mL

    Insulin measurement. Enter 0 if it was not measured; the model pipeline handles missing values.

  • Age years

    Age must be from 20 through 60, inclusive, for this project.

DD. About This ProjectAcademic scope, tools, and limitations

Project objective

This capstone demonstrates a Flask interface for a machine learning classifier that uses five selected health features to show a preliminary binary risk pattern for adults aged 20–60.

Technology

Python, Flask, Scikit-learn, Pandas, NumPy, HTML, CSS, and Joblib.

Limitations

  • The model is intended for the stated age range and the dataset used for this project.
  • The source dataset has no records at exactly age 20; its youngest observed record is age 21.
  • The output is a binary model classification, not a diagnosis, probability, or complete clinical assessment.
  • Results depend on data quality and may not generalize to other populations or settings.
